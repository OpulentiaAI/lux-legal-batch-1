B. *La reconnaissance implicite des scissions transfrontalières,* *mais un régime absent*
**318. Une reconnaissance implicite confirmée par le droit fiscal.** Contrairement aux fusions transfrontalières qui faisaient l’objet d’une reconnaissance explicite de l’article 113 du Code de droit international privé belge ainsi que du Titre V*bis* du Code des sociétés belge, les scissions transfrontalières n’étaient pas prévues expressément par le Code des sociétés ou le Code de droit international privé. Il était toutefois généralement considéré que celles-ci étaient possibles¹²³⁶.
