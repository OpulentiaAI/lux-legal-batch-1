1.3. *Révocation* La révocation du gérant s’opère différemment selon le type de gérant, associé ou tiers, statutaire ou non. Si le gérant est associé commandité, sauf clause contraire, sa révocation se confond avec sa révocation comme associé commandité. Il est alors nécessaire de modifier le contrat de société pour le révoquer. Si le gérant n’est pas associé commandité, sauf clause contraire dans le contrat de société, sa révocation revient à l’associé commandité
90 qui pourra révoquer le gérant comme tout mandataire ad nutum, c’est-à-dire sans préavis, ni juste motif de révocation 91. Si le gérant n’est pas associé, mais nommé dans les statuts, la même majorité doit être obtenue (l’assen- timent d’associés représentant les trois quarts des parts d’intérêts et dans tous les cas, l’assentiment de tous les associés commandités). Si le gérant est un tiers et n’est pas nommé dans les statuts, le régime de révocation des statuts s’applique.
