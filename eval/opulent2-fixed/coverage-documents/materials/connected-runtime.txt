Connected runtime continuation

Run these small phases early while the existing useful child works. This supplements coverage-plan.md; it does not replace its original documents, complete guides/help, useful source review, source-to-pixels checks, all 40 approved-tool gates or cleanup. Harvey, budgets, permissions, approvals, provider and evidence policies remain unchanged. Nothing below is a completed result or a legal answer.

Dependencies: checkpoint, delegation, controlDraft and controlStart are the persistent plain-data results of this session's actual startup. Inspect their complete successful creation/start outcomes first. Reuse their returned IDs and paths, never historical audit identities. Do not create another source or control child, repeat nesting, or stop useful work to manufacture a lifecycle outcome. Preserve completed phases; do not replay their writes/processes/messages to recover an unseen output.

Each named block is one execute program. Native direct calls in one assistant response are serial. The early program overlaps independent calls and persists every whole outcome; follow it with its individual return programs in the same response. Likewise, subsequent connected programs and individual returns can share a response when their dependencies and schemas are already known, without another procedural inference round. All observations must reach an actual completed answerer request before closure. Do not return a large aggregate or substitute counts, selected fields or a preview for the original outcomes.

Before each phase, discover only missing schemas with describe: early needs task.get and todo.write; skills needs skill.list; checkpoint needs task.update/task.list; scratch needs capy.applyPatch/capy.agrep; steering needs message.agent/subagent.message; corpus needs lx.documents/lx.search/lx.chunk/capy.agrep; notes need memory.save/drive.write/drive.read/drive.list/drive.delete; processes need operation.get/list/cancel and capy.wait; lifecycle needs subagent.get/events/stop; observations need subagent.list/session.get/events. Initial function mirrors have identical arguments. Read the complete installed computer guide separately before browser/computer, then discover only their missing action shapes. A different actual schema wins over these source-checked examples.

Overflow is explicit pending work, not consultation. If any returned outcome is file_backed_result, use direct read on its actual output_path, not another oversized execute wrapper. Fully recover every original JSON result/window, using next_character_offset and next_offset until exhausted, and validate its actual length/hash against the retained reference. A backing failure or mismatch stays visible. Return the complete recovery, not just validation metadata. observed() requires the complete record.returned_result in actual completed answerer inputs; merely storing or parsing an unseen result does not satisfy it. After observing complete outcomes, release unneeded large bindings rather than exceeding the unchanged plain-data limit.
