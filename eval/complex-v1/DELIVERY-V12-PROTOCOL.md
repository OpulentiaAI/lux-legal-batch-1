Select `--instruction-profile opulent-delivery-v12 --model-profile runanywhere-mimo-v2.6-pro --semantic-surface toolbox` and a fresh output directory. Default and earlier profiles remain available.

Its source-span ledger records preserved text, narrow general-professional persona edits and necessary runtime/security compatibility adaptations. Packed reads carry consecutive records in one protected stdout receipt within the unchanged 8,192-byte page and 60,000-byte envelope. Snapshot, view, revision, cursor, ownership, explicit decision/limitation and finish-seal requirements remain. An unconfirmed assessment receives exact separate-cell recovery guidance, not an automatic acceptance.
